D2L 学习日志：现代 CNN：AlexNet、VGG、NiN、GoogLeNet 与 BatchNorm

发表于2026-08-18|更新于2026-08-20|Deep Learning
|浏览量:

今日状态

现代 CNN 7.1–7.5 第一遍推进完成。信息密度很高，多个模型都围绕“怎样更有效地组织特征”展开。

一、AlexNet：不只是“比 LeNet 更深”

AlexNet 的变化是一组组合拳：

方向 体现
容量 更深、更宽的卷积与全连接结构
激活 使用 ReLU，减轻深层训练中的梯度问题
泛化 Dropout、数据增强
空间处理 更大的早期步幅/卷积设置
训练条件 更大数据与 GPU 计算条件

第一次概括只说成“层数、池化和全连接更多”，后来补回了 ReLU、Dropout、数据增强和硬件条件。AlexNet 小测约 9/10。

二、VGG：把网络写成可复用的 block

VGG 的视觉结构可以写成：

当天曾把“重复 3×3”理解成输出会自动增加。修正后的规则是：

  • kernel size 决定局部感受范围；
  • out_channels 决定输出通道数；
  • block 是组织重复结构的工程抽象；
  • 池化通常让 H/W 减半，通道数可以在 block 之间增加，但不是池化自动完成的定律。

两个连续 3×3 卷积可以获得接近 5×5 的感受野，同时多一次非线性和参数分解。VGG 小测约 9/10。

三、NiN：用 1×1 卷积处理通道混合

1×1 Conv 不会扩大空间邻域，但会在每一个 (H,W) 位置上混合通道，并配合 ReLU 提供逐位置的非线性变换。NiN block 可概括为：
