二、一个重要纠正：输入数量不等于类别数量

实际上这是两个完全不同的概念。

输入维度决定：

一个样本包含多少个特征。

输出维度决定：

一共有多少个待分类类别。

[
\boxed{\text{输入维度}=\text{特征数量}}
]

[
\boxed{\text{输出维度}=\text{类别数量}}
]

两者不存在必须相等的关系。

三、为什么分类不能直接计算“残差”

这一点今天终于完全想通了。

在线性回归中：

[
y=100,\qquad \hat y=80
]

那么：

[
\hat y-y=-20
]

这种差值是有实际意义的。

因为：

80 和 100 本来就是可以比较距离的连续数值。

所以可以继续使用平方损失：

[
(\hat y-y)^2
]

但是分类标签不同。

假设人为定义：

如果真实答案是猫，而模型预测鸟：

[
2-0=2
]

并不能说明：

“预测成鸟比预测成狗错得多一倍。”

因为：

只是类别编号。

它们没有真正的数值距离意义。

猫、狗、鸟在分类意义上都是平等的离散类别。

因此：

分类任务不能简单拿类别编号做数值残差。

这也是为什么需要概率与交叉熵。

四、交叉熵终于理解了

这是今天最大的突破。

一开始看到：

[
L=-\sum_jy_j\log\hat y_j
]

感觉公式非常复杂。

后来发现，对于普通 one-hot 分类来说，它实际上非常简单。

假设真实标签是：

one-hot 表示：

[
y=[0,1,0]
]

模型预测：

[
\hat y=[0.1,0.8,0.1]
]

代入交叉熵：

[
L
=

-\left(
0\log0.1+
1\log0.8+
0\log0.1
\right)
]

因为另外两个类别对应的真实标签是 0，因此直接消失：

[
\boxed{L=-\log0.8}
]

所以对于这种分类任务，交叉熵最重要的直觉其实就是：

看模型给正确类别分配了多大的概率。

例如：

因此交叉熵特别惩罚：

非常自信但预测错误的模型。

五、修正了一个交叉熵公式错误

测试过程中，我一度认为损失可能是：

[
-\log(1-p)
]

后来纠正：

正确的是：

[
\boxed{-\log(p_{\text{正确类别}})}
]

例如真实类别概率是：

[
0.6
]

那么损失直接是：

[
-\log(0.6)
]

而不是：

[
-\log(1-0.6)
]

这个错误今天已经纠正。

六、交叉熵与线性回归损失函数的关系

现在可以把两者放在一起理解。

回归

关注：

预测的连续数值距离真实连续数值有多远？

因此可以使用：

[
(\hat y-y)^2
]

分类

关注：

模型给真实类别分配了多少概率？

因此可以使用：

[
-\log(p_{\text{correct}})
]

所以：

平方损失和交叉熵承担的是类似角色——都是告诉模型“预测错得有多严重”。

只是两者面对的预测空间不同。

回归面对：

分类面对：

这也是今天理解 Softmax 最重要的一层。

七、熵和交叉熵并不是一回事

之前我觉得：

熵是不是有点像误差或者残差？

今天进一步进行了区分。

熵 Entropy

描述的是：

一个概率分布本身有多不确定。

例如：

非常确定，熵比较低。

而：

非常不确定，熵比较高。

交叉熵 Cross Entropy

训练分类模型时，则更关注：

模型预测的概率分布和真实答案之间有多不匹配。

因此目前第一遍学习时，可以暂时理解为：

交叉熵是分类任务中的损失函数。

不需要现在深入整个信息论体系。

八、理解 Softmax + Cross Entropy 的梯度方向

这一部分也有明显进展。

假设真实标签：

[
y=[0,1,0]
]

模型预测：

[
\hat y=[0.7,0.2,0.1]
]

则：

这正好对应 Softmax + Cross Entropy 中非常重要的结果：

[

\frac{\partial L}{\partial o}

\hat y-y
]

第一遍不要求推导这个公式。

但是已经能够理解它表达的意义：

正确类别预测太低，就往上推；错误类别预测太高，就往下压。

测试时曾口头把“提高/降低”说反，但实际想表达的是：

类别 1、3 相对于目标值 0 偏高，所以应该降低；类别 2 相对于目标值 1 偏低，所以应该提高。

概念本身已经理解。
