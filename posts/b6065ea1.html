D2L 学习日志：反向传播、Kaggle 与 Docker

发表于2026-08-14|更新于2026-08-20|Deep Learning
|浏览量:

今日状态

D2L 第 4 章收束；同时出现了 Kaggle 实战、IPADS 工具链与 Docker 环境准备，是一轮明显的高负荷学习日。

一、backward() 不更新参数

前向传播计算中间结果、logits 与 loss；计算图记录它们之间的依赖；反向传播从 loss 出发，沿计算图使用链式法则求梯度。

当天一度把 backward() 和“参数已经更新”混在一起，之后用 step() 重新划界。还补上了一个重要代价：训练要保存激活和计算图，所以通常比推理更占显存。

二、数值稳定性与初始化：先抓住机制

这一部分没有强行把所有推导背下来，而是先留下三个可复用的判断：

  • 多层链式相乘可能造成梯度消失或爆炸；
  • Sigmoid 在饱和区导数很小，深层传播容易变弱；
  • 全零初始化会让同一层神经元保持对称，学不到不同特征。

Xavier 初始化的核心直觉是控制权重尺度，使前向激活与反向梯度的方差不要在层层传播中迅速放大或缩小。常见的方差量级写成：

三、分布偏移：4.9 的第一次测验暴露了三个坑

三个概念被重新对齐：

类型 变化的部分 直觉
Covariate shift $P(x)$ 变，$P(y \mid x)$ 相对稳定 输入环境变了
Label shift $P(y)$ 变，$P(x \mid y)$ 相对稳定 类别比例变了
Concept shift $P(y \mid x)$ 变 输入与标签的关系变了

第一次小测约 7/10，主要错在 Label shift、经验风险与真实风险、域分类器的用途。针对性补充后，能够回答：

  • 经验风险是在有限训练样本上的平均损失；
  • 真实风险是目标分布上的期望损失；
  • 域分类器可以帮助判断训练域和测试域是否容易被区分，从而提示分布变化。

4.9 后续复测约 2.5/3，第一遍约 80%–85% 通过。

两个概念的纠偏

  • Adam 是优化器，不是另一种模型；
  • K-fold 是训练集内部的验证方式，不是 Kaggle 测试集；选好超参数后，再用全部训练数据重训，最后对标签隐藏的测试集预测。

House Prices 最终成功提交，4.10 约 8–8.5/10，标志着第 4 章从公式、训练机制、分布问题走到了完整项目。

五、同日的工程支线：为 IPADS 做准备

学习记录还覆盖了一个工程分支：Shell、Git 的优先级，Docker 的 Image/Container 区别，以及 docker load、docker run、docker exec、bind mount 的基本作用。

面对 vpm_run_toolchain.tar.gz 时，先确认它是不是 Docker image，再决定是否 docker load；不能看到 .tar.gz 就直接当成镜像。

WSL 的 403、VirtualMachinePlatform、BIOS 虚拟化和 Docker Desktop 的关系，也被视为环境层问题，不与 D2L 模型错误混为一谈。

阶段结论：第 4 章已闭环；下一步进入 PyTorch 模型组织与 CNN 基础。
